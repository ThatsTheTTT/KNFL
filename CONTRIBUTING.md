# Contributing to KNLF

Thank you for your interest in contributing to KNLF! We welcome contributions from developers of all skill levels, whether you are fixing bugs, improving compression performance, or updating documentation.

---

## How to Contribute

### 1. Reporting Bugs
If you find a bug or unexpected behavior:
1. Check the [Issues](../../issues) tab to see if it has already been reported.
2. If not, open a new Issue.
3. Include clear steps to reproduce the issue, along with details about your compiler, platform, and sample input files if applicable.

### 2. Suggesting Enhancements
Have an idea to improve KNLF?
1. Open an Issue with the tag `enhancement`.
2. Describe the feature, why it would be beneficial, and how it aligns with KNLF's focus on low RAM footprint and streaming efficiency.

### 3. Submitting Code (Pull Requests)
1. **Fork** the repository and create your feature branch from `main`:
